Exquisiteses gastronomiques - aplicacio de consola C++17

Estructura:
- Una classe per fitxer .h i .cpp: Vi, Plat, CapaDeDades, CapaDeDomini i CapaDePresentacio.
- Enumeracions.h conté les enumeracions ColorVi i Mes.
- FuncionsDomini.h/.cpp conté funcions auxiliars que no pertanyen a cap classe.
- disseny_gastronom.cpp conté el punt d'entrada de l'aplicació.

Compilació amb g++:
g++ -std=c++17 -Wall -Wextra -pedantic *.cpp -o exquisiteses

Execució:
./exquisiteses

Les dades inicials són dades d'exemple per poder provar les operacions a classe.
